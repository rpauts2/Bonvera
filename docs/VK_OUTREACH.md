# VK Outreach — настройка и эксплуатация

## Что делает модуль

VK Outreach — дополнительный канал Bonvera на общем backend и PostgreSQL. Он не заменяет Telegram-бота.

Путь пользователя:

1. Пользователь приходит из официальной VK-рекламы и сам открывает диалог сообщества.
2. Бот объясняет обработку данных и запрашивает отдельное согласие.
3. Пользователь отдельно выбирает, хочет ли получать рекламу в дальнейшем.
4. Пользователь отправляет номер телефона. Он сохраняется в зашифрованном виде.
5. Бот показывает четыре прямые ссылки на МФО и пятую ссылку на CPA-витрину владельца.
6. Каждый переход проходит через внутренний redirect и сохраняет VK contact, campaign, source и slot.
7. Реальные конверсии можно считать только после партнёрского postback/API или отчёта.

VK ID — отдельная сущность, он не смешивается с Telegram ID.

## Настройка VK-сообщества

1. Создать или выбрать VK-сообщество Bonvera.
2. Включить сообщения сообщества.
3. В настройках сообщества включить Callback API и указать:
   - URL: `https://<домен-Bonvera>/vk/callback`
   - Secret key: значение `VK_CALLBACK_SECRET`
   - Confirmation string: значение `VK_CONFIRMATION`
   - событие `message_new`.
4. Создать токен доступа сообщества с минимальными правами, необходимыми для отправки и проверки сообщений.
5. Проверить, что callback confirmation проходит и тестовое сообщение пользователя приходит в Bonvera.

VK-настройки окружения:

| Переменная | Назначение |
|---|---|
| `VK_ENABLED` | Включение канала. По умолчанию `false` |
| `VK_GROUP_ID` | Числовой ID сообщества |
| `VK_GROUP_TOKEN` | Токен доступа сообщества. Хранить только в secret storage хостинга |
| `VK_CALLBACK_SECRET` | Secret key Callback API |
| `VK_CONFIRMATION` | Строка подтверждения Callback API |
| `VK_API_VERSION` | Зафиксированная версия VK API |
| `VK_API_TIMEOUT_S` | Таймаут запросов |
| `VK_COMMUNITY_URL` | `https://vk.me/<slug>` или `https://vk.com/write-<group_id>` |
| `VK_PUBLIC_BASE_URL` | Публичный HTTPS origin Bonvera для tracked links |
| `VK_PRIVACY_URL` | Публичная HTTPS-ссылка на политику обработки данных |
| `VK_OPERATOR_NAME` | Юридическое наименование оператора персональных данных |
| `VK_MAX_CAMPAIGN_MESSAGES_30D` | Максимум рекламных сообщений на одного пользователя за 30 дней; default 4 |
| `VK_MIN_CAMPAIGN_INTERVAL_HOURS` | Минимальный интервал между рекламными сообщениями; default 24 |

Не отправлять токен сообщества в чат и не коммитить его в Git. Включать `VK_ENABLED=true` только после настройки всех обязательных полей и теста callback. Пока VK выключен, Telegram продолжает работать.

## Пять ссылок МФО

Открыть админку Bonvera и перейти в **VK Marketing → Пять ссылок**.

- Слоты 1–4: название рекламодателя, заголовок кнопки, HTTPS partner URL, tracking parameter и описание.
- Слот 5: **CPA-витрина**. Поле намеренно пустое, пока владелец не вставит URL из своего CPA-кабинета.

Нельзя включать слот без URL и названия рекламодателя. Каждый URL должен быть проверен владельцем в партнёрском кабинете; tracking parameter задаётся строго по документации конкретной сети. Система не генерирует партнёрские ссылки и не угадывает названия/параметры.

В диалоге пользователю показываются только активные и корректно настроенные слоты. Для перехода создаётся непрозрачный click token. Номер телефона и VK ID не передаются в URL.

## Рекламные кампании и поиск новой аудитории

Открыть **VK Marketing → Кампании**.

1. Создать черновик.
2. Заполнить юридическое наименование рекламодателя, ИНН и ERID.
3. Подготовить рекламный текст. Обязательное предупреждение о рисках добавляется системой.
4. Сохранить черновик.
5. Нажать **Ссылка для VK Ads** и скопировать индивидуальную ссылку кампании.
6. Использовать её как адрес перехода в рекламном объявлении VK, которое открывает диалог сообщества.
7. Вернуться в Bonvera, сделать preview и запустить только после проверки кампании и аудитории.

MVP генерирует deep link с подписанным campaign ref и фиксирует источник, но пока не создаёт и не оплачивает рекламные кампании автоматически через VK Ads API. Создание объявления/аудитории выполняется в официальном кабинете рекламодателя. Не использовать таргетинг по предполагаемым долгам, просрочкам или плохой кредитной истории конкретного человека.

Массовый текст не должен заявлять «вам одобрен займ», «предодобрено», «одобряем всем» или «100% одобрение», если нет реального индивидуального подтверждения конкретной МФО. В первой версии интеграции персонального pre-approval нет.

## Импорт списка

Открыть **VK Marketing → Контакты и импорт**.

CSV должен содержать VK ID и две независимые группы доказательств:

```csv
vk_user_id,personal_data_consent_at,personal_data_consent_source,personal_data_consent_version,personal_data_consent_proof,marketing_consent_at,marketing_consent_source,marketing_consent_version,marketing_consent_proof
123456,2026-11-20T10:00:00Z,web-form,privacy-v1,privacy-proof-123,2026-11-20T10:00:00Z,web-form,marketing-v1,marketing-proof-123
```

- Дата — ISO 8601.
- Источник, версия текста и ссылка/ID доказательства обязательны отдельно для каждого согласия.
- Preview проверяет структуру, дату, дубликаты и наличие подтверждающих ссылок. Он не может автоматически доказать подлинность документов или юридическую достаточность согласия.
- После импорта записи получают статус **Ожидает ручной проверки**.
- Администратор должен открыть и проверить оба доказательства вне системы, затем нажать **Проверил доказательства — допустить** или **Отклонить**.
- Только запись со статусом `verified`, актуальным согласием на обработку и рекламным согласием может рассматриваться для рекламной кампании.
- Если пользователь отозвал согласие/нажал «Стоп», повторный импорт старой строки не разблокирует его.

Список телефонных номеров без VK ID не является адресной книгой VK и не позволяет сообществу начать с ними переписку. Не искать соответствующие профили, не собирать ID участников чужих групп и не писать незнакомым людям первым.

## Запуск кампании

Перед запуском система проверяет:

- VK включён и настроен;
- рекламный текст содержит рекламодателя и обязательное предупреждение;
- указаны 10/12-значный ИНН и ERID;
- все пять ссылок активны и настроены;
- пользователь дал отдельные согласия;
- импортированные согласия прошли ручную проверку;
- VK разрешает сообществу отправлять сообщения конкретному получателю;
- пользователь не отписался/не попал в suppression list;
- не превышена частота отправки.

По умолчанию: максимум 4 рекламных сообщения за 30 дней и не чаще одного сообщения за 24 часа на пользователя. Лимиты можно менять в окружении.

Кампании хранятся в PostgreSQL. Отправка идёт небольшими пачками, имеет состояния, обработку временных ошибок и pause/resume. Неизвестный результат отправки не должен приводить к бесконтрольной повторной отправке.

## Проверки перед активацией

- [ ] Проверен Callback confirmation.
- [ ] Входящее сообщение из тестового VK-пользователя создаёт контакт.
- [ ] Отказ от обработки данных не запрашивает телефон.
- [ ] Отказ от рекламы не блокирует текущую витрину.
- [ ] Телефон сохраняется только зашифрованным.
- [ ] Четыре МФО-ссылки ведут на нужные страницы и передают заданный sub-ID.
- [ ] Пятая CPA-ссылка введена владельцем и проверена.
- [ ] Все пять кнопок правильно учитываются в кликах.
- [ ] Кампанийный ref связывается со входящим диалогом и последующими кликами.
- [ ] CSV без двух доказательств отклоняется.
- [ ] Импортированный контакт остаётся pending review до решения администратора.
- [ ] Контакт без VK permission пропускается.
- [ ] Отписавшийся пользователь не получает последующие рекламные сообщения.
- [ ] Частотные ограничения работают между несколькими кампаниями.
- [ ] Кампания приостанавливается и продолжается после перезапуска.
- [ ] Реальный MFO postback или импорт отчёта проверен отдельно.

## Ограничения MVP

- VK Ads API автоматическое создание и управление объявлениями пока не подключено. Bonvera выдаёт campaign deep link и рекламный текст, а размещение настраивается в официальном рекламном кабинете.
- Четыре партнёрские ссылки и пятая CPA-витрина вводятся владельцем. В репозитории нет этих внешних URL.
- Реальная атрибуция конверсии требует postback/API/отчёта CPA-сети. Пока фиксируются клики.
- Bot не проверяет юридическую подлинность доказательств CSV автоматически; для импортированных контактов предусмотрена ручная проверка. Юридическую достаточность процесса должен подтвердить ответственный специалист.
- VK-канал отключён до настройки сообщества, токена и публичного HTTPS. Реальные сообщения/кампании не запускаются автоматически после деплоя.
