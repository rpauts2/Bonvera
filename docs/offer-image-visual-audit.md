## Важные замечания

- Семь активных SVG не означают семь подтверждённых фотографий реальных карт. Четыре изображения действительно показывают карту крупно.
- Все исходники официальные, но кроме Т-Банка коммерческие права на повторное использование отдельно не подтверждены. Публичная доступность картинки не равна разрешению на коммерческое использование.
- Остальные девять карточных офферов пока используют прежние JPG, для которых точность дизайна карты не подтверждена.
- Wayment — виртуальная карта/сервис, поэтому нельзя подменять его выдуманной пластиковой картой. Нужен официальный скрин/рендер виртуальной карты от самого Wayment.
- Для каждого банка нужно установить конкретный продукт по офферу. Если в каталоге указано только название банка, не следует самостоятельно выбирать произвольную карту этого банка.

## Следующие точные кандидаты на поиск

1. ОТП Банк — на официальной странице найдено изображение ab_test_4eaf7e2633.webp, но это промо-графика, а не подтверждённый чистый рендер карты. Нужен отдельный продуктовый визуал с официальной страницы списка карт.
2. БСПБ — у банка несколько дебетовых продуктов («Яркая», «ЯСЧИТАЮ», Cash Back и др.); оффер не указывает точный вариант.
3. Ак Барс — официальный продукт «Ак Барс Карта»; требуется получить чистый card render.
4. Ренессанс — официальный продукт «Главная МИР»; требуется получить чистый card render.
5. ФОРА — каталог говорит только «ФОРА Банк», хотя у банка несколько продуктов. Нужен точный вариант оффера.
6. Ozon Банк — на официальном сайте есть несколько дизайнов; использовать можно только дизайн, соответствующий партнёрскому офферу.
7. МКБ — оффер не указывает конкретный вариант продукта; требуется уточнение.
8. Wayment — только реальный официальный визуал виртуальной карты/экрана продукта.

## Рекомендация

Не заменять оставшиеся JPG случайными найденными картинками. Для точного попадания в референс лучше получить от партнёрских сетей или банков media kit/разрешённые изображения конкретных продуктов. Для непроверенных офферов использовать аккуратный брендовый арт без изображения выдуманной карты.
